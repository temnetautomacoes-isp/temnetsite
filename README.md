# TemNet — A sua conexão completa

Landing page profissional desenvolvida para a **TemNet**, provedor de telecomunicações de ultravelocidade em fibra óptica, Link Dedicado corporativo e soluções completas em infraestrutura de redes e T.I em **Alagoinhas**, **Aramari**, **Ouriçangas** e em toda a **Bahia**.

---

## 🚀 Tecnologias Utilizadas

- **React 18** + **TypeScript**
- **Vite** (Build tool e servidor ultrarrápido)
- **Vanilla CSS** com Design Tokens e Sistema Suíço Minimalista (*ui-ux-pro-max*)
- **Lucide React** (Ícones em vetor limpo monocromático)

---

## 🌐 Estrutura da Aplicação

- **Navbar**: Header flutuante em *glassmorphism* com seletor de cidades e ação rápida.
- **Hero**: Headline de alto impacto, prova social e telemetria de rede ao vivo (Ping dinâmico, Uptime 99.98%, SLA).
- **Benefícios**: 4 pilares estratégicos (Fibra 100% Pura, Link Dedicado, Infra de T.I e Suporte Local).
- **Como Funciona**: 3 etapas simples para contratação e ativação ágil.
- **Serviços & T.I**: Showcase interativo em abas para Banda Larga, Link Dedicado, Cabeamento Estruturado e Manutenção de Hardware.
- **Cobertura Regional**: Hierarquia de atendimento (1º Alagoinhas Polo, 2º Aramari, 3º Ouriçangas e atendimento corporativo em toda a Bahia).
- **Planos e Preços**: Switcher interativo entre planos Residenciais e Corporativos com especificações técnicas.
- **Depoimentos**: Prova social de empresários e clientes reais da região.
- **FAQ**: Perguntas frequentes em formato accordion acessível.
- **CTA Final**: Seção de conversão de alto padrão.
- **Modal de Viabilidade**: Verificador rápido com integração direta ao WhatsApp.

---

## 🛠️ Como Executar Localmente

### Pré-requisitos
- Node.js (v18+)
- npm ou yarn

### Instalação
```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```

O site estará disponível em `http://localhost:3000`.

### Build de Produção
```bash
npm run build
```
